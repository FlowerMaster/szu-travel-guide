# 来深圳大学怎么玩

深圳大学粤海 × 沧海互动旅行地图 MVP。

## 当前已完成

- 5 种路线玩法：经典参观、拍照出片、亲子遛娃、安静散步、人文建筑
- 自由探索入口
- 校园地图展示、节点、路线顺序示意、缩放和拖动
- 地点详情卡片与完整 49 个 720 云场景清单
- 地点代表图懒加载
- 720 云全景沉浸层和返回地图
- 独立的“预约与到达”子页面，首页不展开预约规则
- 深大食堂与菜品经验卡片，独立区分听荔餐厅和听山餐厅；点击可打开食堂详情与菜品页，不跳转外部平台
- 从北门、东北门、沧海校区出口连接周边吃喝玩乐路线
- 桌面端、移动端 Bottom Sheet、浅色与深色模式

## 本地运行

```bash
npm install
npm run dev
```

构建检查：

```bash
npm run build
```

## 数据边界

- 地点名称、scene_id 和代表图来自项目已保存的 720 云场景清单。
- 地图上的路线连线是游览顺序示意，不是精确步行导航。
- 预约名额、开放时间、校门和建筑进入权限必须以官方最新信息为准。
- 小红书、抖音等内容只作为游客经验，不替代官方规则。

## 主要目录

- `src/data/places.ts`：核心地点卡片
- `src/data/routes.ts`：玩法路线
- `src/data/nearby.ts`：出校门后的周边路线
- `src/data/canteens.ts`：食堂和菜品经验
- `src/data/sceneManifest.json`：49 个场景清单
- `public/assets/map/`：去除二维码后的校园地图
- `public/assets/places/`：49 张代表图

社交平台内容只作为内部研究来源，不直接复制进公开页面；食堂卡片使用已保存的校园餐厅环境图和深圳大学后勤公开菜品图，避免把游客照片或未经授权的菜品图当作可再发布素材。
